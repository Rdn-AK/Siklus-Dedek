Panduan Perhatian Mbull 💖

Tips utama mendampingi Dede di tiap fase siklus

Care Guide
3–5 Hari Sebelum Haid (Fase PMS)
  • • Wajar jika makan lebih banyak atau emosi agak sensitif.
  • • Sabar saat ada ngambek kecil, temani dengan tenang.
  • • Ingatkan stok pembalut dan Feminax dengan lembut.
Hari 1 & 2 (Paling Nyeri)
  • • Tanyakan kondisi perutnya dengan perhatian tulus.
  • • Tawarkan kompres hangat, Kiranti, atau cokelat kesukaannya.
  • • Hindari mengajak aktivitas fisik berat.
Selama Periode Berlangsung
  • • Tetap hangat dan responsif, hindari adu argumen.
  • • Jangan menyinggung hal sensitif atau bercanda berlebihan.
Perhatian Khusus
  • • Jika nyeri ekstrem hingga muntah/berlangsung >14 hari, sarankan periksa ke dokter dengan lembut.

Rangkuman Gejala & Catatan Dede

Gejala Paling Sering

Sakit perut/keram hampir selalu dirasakan pada hari 1-2. Kadang disertai pusing & demam ringan.

Pola PMS (1-3 Hari Sebelum)

Nafsu makan meningkat & emosi lebih sensitif 1-3 hari sebelum haid datang.

Catatan Khusus

Periode Juni (#4) & Oktober (#8) berlangsung lebih lama (12-18 hari) dengan pola sempat berhenti lalu keluar lagi.

Google Sheets 2-Way Sync

Integrasi otomatis dengan Apps Script

Aplikasi Terhubung Secara Otomatis

Data tersinkronkan langsung ke Google Sheet yang sudah dikonfigurasi.

Kode Apps Script (Google Spreadsheet): 
function doGet() {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var rows = sheet.getDataRange().getValues();
    if (rows.length <= 1) {
      return ContentService.createTextOutput(JSON.stringify([])).setMimeType(ContentService.MimeType.JSON);
    }
    var periods = [];
    for (var i = 1; i < rows.length; i++) {
      var r = rows[i];
      if (!r[0] && !r[1]) continue;
      periods.push({
        id: String(r[0] || ("p_" + i)),
        startDate: formatDate(r[1]),
        endDate: formatDate(r[2]),
        duration: Number(r[3]) || 1,
        cycleLength: r[4] ? Number(r[4]) : null,
        flow: r[6] ? String(r[6]) : "Sedang",
        symptoms: r[5] ? String(r[5]).split(", ").filter(Boolean) : [],
        notes: r[7] ? String(r[7]) : ""
      });
    }
    return ContentService.createTextOutput(JSON.stringify(periods)).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify([])).setMimeType(ContentService.MimeType.JSON);
  }
}

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var periods = JSON.parse(e.postData.contents);
    sheet.clear();
    sheet.appendRow(["ID", "Tanggal Mulai", "Tanggal Selesai", "Durasi (Hari)", "Jarak Siklus", "Aliran", "Gejala", "Catatan"]);
    for (var i = 0; i < periods.length; i++) {
      var p = periods[i];
      var sym = Array.isArray(p.symptoms) ? p.symptoms.join(", ") : (p.symptoms || "");
      sheet.appendRow([
        p.id || ("p_" + (i+1)),
        p.startDate || "",
        p.endDate || "",
        p.duration || 1,
        p.cycleLength || "",
        p.flow || "Sedang",
        sym,
        p.notes || ""
      ]);
    }
    return ContentService.createTextOutput(JSON.stringify({ status: "success" })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() })).setMimeType(ContentService.MimeType.JSON);
  }
}

function formatDate(dt) {
  if (!dt) return "";
  if (dt instanceof Date) {
    var y = dt.getFullYear();
    var m = ("0" + (dt.getMonth() + 1)).slice(-2);
    var d = ("0" + dt.getDate()).slice(-2);
    return y + "-" + m + "-" + d;
  }
  return String(dt).trim();
}
